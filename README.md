# Pitz Pulse

Triage inteligente de solicitudes internas: recibe mensajes en español o portugués y devuelve una clasificación estructurada (categoría, prioridad, área sugerida, resumen y pregunta de seguimiento).

> 🚧 En construcción. Las instrucciones completas de instalación y uso se agregarán al terminar el backend.

## Setup rápido

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
cp .env.example .env
```
